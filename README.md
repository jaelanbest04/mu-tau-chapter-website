# Mu Tau Chapter Website

## Pages
- `index.html` — Home
- `programs.html` — Initiatives and staple programs
- `history.html` — History with Alpha Phi Alpha link
- `lineage.html` — Lineage page
- `contact.html` — Contact and email list signup

## Customize
1. Replace placeholder email and Instagram in `contact.html`.
2. Replace the Google Form button link in `contact.html`.
3. Add probate/stroll photos to `assets/images/`.
4. Add videos to `assets/videos/`.
5. Replace placeholder media boxes with `<img>` or `<video>` tags.

## Run
Open `index.html` in a browser, or upload the whole folder to Netlify/Vercel/GitHub Pages.
